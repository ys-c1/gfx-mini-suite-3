# 相邻遮挡段合并报告（mini-shadow-cast）

## 能力

`shadow_merge_segments(segs, nseg, tol, out, out_cap)`：把共线且相邻（端点间隙与
线间垂直距离均 `<= tol`）的遮挡段并成一条轮廓再投影，重叠区只投影一次。
方向共线用固定角阈值 1e-6 rad 判定，**不随 tol 放宽**，因此容差再大也不会把
拐角/T 型结构并掉。合并端点一律回读原始输入顶点，不引入新坐标。

确定性约定（均有单元测试覆盖）：

| 情况 | 结果 |
|---|---|
| `tol == 0` | 仅精确共线且精确相接/重叠的段合并 |
| `tol` 过大 | 所有共线段并成一条跨极值端的段（轮廓退化但确定）；非共线段永不合并 |
| `nseg == 0` | 返回 0，`out` 不改动 |
| 零长度段 | 视为退化，一律丢弃 |
| `tol < 0` 或 NaN | 返回 -1 |

单条遮挡物合并前后位级一致（`memcmp` 验证），投影与遮挡判定结果不变。

## 四组场景（`make report`，亮度模型：每段遮挡 50%，单遮挡物基准 0.50）

| 场景 | 输入段数 | 合并后段数 (tol=0 / tol=推荐) | 重叠区最低亮度 前→后 | 接缝跳变 前→后 | 合并耗时 |
|---|---|---|---|---|---|
| S1 相邻接缝 `data/scene_adjacent.dat` | 2 | 1 / 1 (tol=0.01) | 0.00 → 0.50 | 0.50 → 0.00 | <0.001 ms |
| S2 重叠链 `data/scene_overlap.dat` | 4 | 1 / 1 (tol=0.05) | 0.00 → 0.50 | 0.50 → 0.00 | <0.001 ms |
| S3 混合轮廓 `data/scene_mixed.dat` | 5 | 4 / 4 (tol=0.05) | 0.00 → 0.50 | 0.50 → 0.00 | <0.001 ms |
| S4 长链性能（4096 段，程序生成） | 4096 | 1 / 1 (tol=0.05) | 0.00 → 0.50 | 0.50 → 0.00 | ≈19 ms |

- S1：两段墙在端点相接，接缝射线被计两次（hits=2），接缝处亮度 0.00、两侧
  0.50，跳变 0.50；合并后整条墙亮度均匀 0.50。
- S2：四段两两重叠，重叠区 hits=2 亮度 0.00；合并为一段后重叠区只投影一次。
- S3：共线重叠对合并（5→4）；T 型竖墙（非共线）、平行错位 2.0 的墙
  （垂直距离 > tol）、间隙 4.0 的远墙（间隙 > tol）全部保留。两段独立墙的
  真实交叠不计入伪影区，保持物理正确的双重遮挡。
- S4：O(n²) 成对判定，4096 段约 19 ms（-O2）。段数到万级仍可接受；
  更大规模可按方向分桶再两两判定。

## 容差取值建议

- 下限：浮点拼合误差量级，约 `1e-6 ~ 1e-4 × 场景尺度`。tol=0 只适用于顶点
  精确共享的数据。
- 上限：`min(不同墙之间的最小真实间隙, 平行墙最小垂直间距, 最短段长)` 的
  1/10 以内。超过真实间隙会把独立的墙并成一条（轮廓退化，结果确定但语义
  错误）。
- 对本报告尺度的场景（段长 1~6，真实间隙 ≥ 2）：**推荐 1e-3 ~ 0.1**，
  默认 0.01（见 `demo.cfg` 的 `merge_tol`）。
