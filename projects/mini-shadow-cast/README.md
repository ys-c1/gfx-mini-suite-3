# mini-shadow-cast

2D 线段投影与遮挡判定，含深度感知的重叠阴影裁剪。

## 构建目标

| 命令 | 内容 |
|---|---|
| `make test` | 单元测试（198 项检查） |
| `make bench` | 四组布光 + 三种特殊输入的多边形/面积/耗时报告 |
| `make converge` | 逐像素采样的网格细化收敛与误差上界对照 |
| `make tool` / `make demo` | 旧的单遮挡物命令行工具（行为保持不变） |

## 重叠裁剪语义

每个遮挡物是一条线段加一个深度值，`shadow_clip_two()` 输出一组**内部互不重叠**
的多边形（`shadow_clip_result_t.piece`），渲染端直接按列表填充即可，重叠区不再
被整片叠暗：

1. 两个遮挡物各自投影成凸四边形（`shadow_occluder_quad`，内部仍调用冻结的
   `shadow_project`）；
2. 按深度确定可见遮挡：深度小者胜出，重叠多边形（`is_overlap=1`）归属胜者；
3. 用 Sutherland–Hodgman 半空间裁剪求两四边形的真实交集多边形，并把各自的
   非重叠部分切成凸分片（`poly_difference`，逐半空间分裂，分片内部两两不交）。

### 三种特殊输入的确定结果

| 输入 | 结果 |
|---|---|
| 深度相同（相对容差 1e-6） | `tie=1`，按较小 `id` 确定性决胜，与参数顺序无关 |
| 深度缺失（`SHADOW_DEPTH_MISSING` = NaN） | 按 +∞ 排序：有深度者胜；两者都缺失则按 `id` 决胜并置 `tie=1`、`depth_missing=1` |
| 两者完全重合 | 只输出一个重叠多边形（面积等于单个四边形），不产生差分片 |

阴影完全不相交时输出两个完整四边形，`winner=-1`，无重叠多边形。

## 面积一致性与误差上界

- 代数恒等：所有分片面积之和恒等于 `area(A)+area(B)-area(A∩B)`，fuzz 2 万组
  最大相对误差约 8.2e-7（浮点舍入量级）；
- 逐像素采样：参考光栅器在 N×N 网格上按单元中心判定。对每条投影边
  (dx,dy)，至多影响 `|dx|/hx + |dy|/hy + 1` 个单元；争议单元最多各贡献
  `hx·hy` 面积。对所有输出边求和即得严格上界

      bound = hx·hy · Σ_edges ( |dx|/hx + |dy|/hy + 1 )

  实测 `|采样面积 − 精确面积|` 在所有网格（32…512）下均严格小于该界，且界随
  网格细化按 1/N 趋于 0（见 `make converge`，报告在 `out/converge_report.txt`）。
  裁剪缝两侧的浮点 ulp 级差异最多翻转边界单元，已被该界显式计入。

## 单遮挡物不变性

`shadow_project` 与 `shadow_point_lit` 的签名和实现未改动；`make demo` 仍输出
`ok span=27.889`，`out/state.bin` 二进制格式不变。新功能全部为增量 API。
