## 碰撞等价性手推（行 14）

探针 AABB `(x,y,bw,bh)=(4,4,10,10)`，tile=8：
覆盖格区间 `x0=floor(4/8)=0 … x1=floor((14-1e-3)/8)=1`，y 同理 → 覆盖
`{0,1}×{0,1}`，含格 (1,1)=A。

- A 关：door_map[5]=1，与 legacy_map[5]=1 逐字节相同 → 两图首命中均
  `(tx,ty)=(1,1)`，返回值都为 1。
- A 开：door_map[5]=0，覆盖区内全 0 → 返回 0；legacy 图仍为 1 → 返回 1。
- A 再关：door_map[5] 重写 1 → 返回 1，等价性恢复。

## 行 8/13 的顺序无关性手推

绝对目标态赋值 `state[i]=sw.state`（不是取反），且批内已禁止同格重复：
正序 `[A→C, B→O]` 与逆序 `[B→O, A→C]` 写不同格，最终都是
`state[A]=C, state[B]=O, map[5]=1, map[10]=0`。若将来允许同格重复，
逆序结果会不同——因此 `-5` 是顺序无关的前置保障。

## 回滚误差手推

快照是整表 `memcpy`（map/state/frame 三张表），回滚也是整表 `memcpy`，
没有逐格合并或差量计算 → 回滚后逐字节差应为 0，不存在累积误差。
bench 里以 `memcmp` 实测确认（见 `bench_door.c` 的 rollback 段）。
