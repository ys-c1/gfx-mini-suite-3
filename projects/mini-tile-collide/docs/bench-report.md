# 门开关基准报告（64 格 / 256 格两档）

`make bench` 运行 `tests/bench_door.c`。布局：`i%3==0` 为永久实心，
其余偶数格为门（门初始关闭）。每格放置一个 8×8 AABB 探针。

## 最近一次结果（本机，gcc 15.2 -O2，CLOCK_MONOTONIC）

| 指标 | 64 格 (8×8, 21 门) | 256 格 (16×16, 85 门) |
|---|---:|---:|
| 关门 vs 全实心参照 命中差 | **0** | **0** |
| 开门 vs 仅永久实心参照 命中差 | **0** | **0** |
| 开门后命中翻转的探针数（门数） | 21 | 85 |
| 外部 restore 回滚字节漂移 | **0** | **0** |
| 内部 rollback_last 漂移 / 二次回滚漂移 | **0 / 0** | **0 / 0** |
| 批量切换耗时（2000 批全门切换） | ~150 ns/批，~7.2 ns/门 | ~1.34 µs/批，~15.8 ns/门 |
| 乱序批 vs 正序批 三表漂移 | **0** | **0** |
| 非法批（越界/非门各 50 次）拒绝数 | 100/100 | 100/100 |

## 读数说明

- **命中差为 0**：关门状态下门图与等价实心图的每个 AABB 判定逐格一致；
  开门后与撤掉门的永久实心图一致。`hit_flip_on_open` 恰好等于门数，
  说明每扇门都真实改变了碰撞结果，没有假门。
- **回滚误差为 0**：快照/回滚均为整表 `memcpy`，回滚后 `map/state/frame`
  三表逐字节相同，无累积误差；二次回滚同样为 0（检查点不被消费）。
- **切换耗时**：单门均摊随规模从 7.2 ns 升到 15.8 ns，主要来自整表快照
  （O(格子数) 的 memcpy），逐门切换本身仍是 O(门数)。64→256 格规模 4 倍、
  门数 4.05 倍，每批耗时约 8.9 倍，差异来自快照按全表而非按门复制。
- 耗时为单次运行值，随机器抖动；结构性结论（漂移为 0、拒绝数 100）是确定性的。
